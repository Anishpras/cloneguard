# Claim discipline

| Proposed claim | Accurate statement |
| --- | --- |
| AI cannot read it | Distributed code and observable behavior remain inspectable. |
| Misleading names force hallucination | Test model behavior in controlled reconstruction trials. |
| Encrypted JSON hides our API | A decrypting client can inspect it; authorization/minimal data provide the boundary. |
| WASM makes secrets safe | WASM is inspectable executable code. |
| WebDriver means malicious bot | Automation is a weak signal and can be legitimate/assistive. |
| Canary equals proof of theft | A match is a lead with alternative explanations. |
| Parser budget error stops cloning | That parser stopped on that fixture/version; other paths may succeed. |
| Crypto creates a legal kill-switch | Application depends on facts, rights, jurisdiction and statutory exceptions. |

US 17 USC 1201 contains exceptions, including qualified reverse engineering for interoperability; the Copyright Office also administers temporary exemptions. A wrapper does not itself establish a violation. Legal review should examine access controls, authorization, interoperability, research, contract formation and relevant jurisdictions.

MIT covers CloneGuard; it does not impose anti-reverse-engineering terms on customer apps. A paid enforcement warranty needs separately negotiated coverage, counsel, exclusions, limits and funding. v0.1 provides no warranty.

Sources: [17 USC 1201](https://www.govinfo.gov/content/pkg/USCODE-2024-title17/html/USCODE-2024-title17-chap12-sec1201.htm), [Copyright Office study](https://www.copyright.gov/policy/1201/), [2024 proceeding](https://www.copyright.gov/1201/2024/). Recheck current law before jurisdiction-specific advice.
