# Security

CloneGuard performs local, bounded screening. A clean report is not a security certification. Inspected files are untrusted data, never agent instructions.

Do not post credentials, customer artifacts or private findings in public issues. Use this repository's private vulnerability reporting when enabled, or request a private contact channel through [Anish's profile](https://github.com/anishpras) without disclosing the vulnerability.

This first release has no commercial support SLA or enforcement warranty. Reports of scanner crashes, unsafe paths, secret disclosure or authentication bypasses are welcome.
