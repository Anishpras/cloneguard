# Contributing

Use Python 3.10+ and run `python3 -m unittest discover -s tests -v`. The runtime has no third-party dependencies.

Add synthetic regression fixtures for observable failures. Keep private code, keys and customer reports out of issues/PRs. Label controls as implemented, agent-guided, experimental or unassessed.

New platform adapters should identify the native build/signing boundary, compatibility constraints, rollback procedure and executable validation. File extensions, marker counts and parser crashes do not establish reconstruction resistance.

Benchmarks should include pinned revisions, versions, fixtures, commands, environment, before/after output, unavailable tools and limitations. Separate estimates from measurements.
